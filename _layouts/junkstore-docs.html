--- layout: junkstore-default --- {%- comment -%} Documentation layout. Separate from junkstore-page, which is built for short marketing pages: full container width, centred headers, justified body copy. None of that suits 24 pages of dense technical reference. Extends junkstore-default, so the announcement bar, masthead and footer stay shared and are maintained in one place. Every rule in _sass/docs.scss is scoped under .js-docs. That is deliberate: it keeps the docs from touching the other pages on the site, and it wins on specificity against the conflicting global code-block rules in _sass/base-styles.scss without deleting anything other pages rely on. {%- endcomment -%} {%- comment -%} Breadcrumbs come from page.breadcrumbs, written by the importer, which reads the same _data/doc_sections.yml this layout uses for every other label. They are not assembled here because Liquid cannot build an array of maps without a plugin, and the shared breadcrumb include (which also emits the schema.org JSON-LD) expects exactly that shape. {%- endcomment -%}
