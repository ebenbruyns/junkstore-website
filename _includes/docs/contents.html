{%- comment -%} The contents page at /docs/. Built from site.docs rather than from a written list, so a page or folder added to the junk-docs repo appears here on the next import with nothing to update by hand. Names and blurbs come from _data/doc_sections.yml, falling back to a title-cased folder name when a section or group is not listed there, so new folders render sensibly rather than blank. Ordering is doc_order, which the importer assigns from the reading order in the docs repo.
