**This week's Pro tip:** Junk Store Pro has built-in power tools you can access instantly from any screen using button shortcuts.

{% include discord-follow.html channels="tips" label="More tips on Discord:" %}

<h2 style="text-align: left !important; margin-left: 0;">Quick Access Shortcuts</h2>

**Press and hold SELECT** on any screen to see all available shortcuts:

- **SELECT + A** - Settings
- **SELECT + B** - File Operations
- **SELECT + X** - File Browser
- **SELECT + Y** - Diagnostics

The shortcut overlay appears whenever you hold SELECT, so there is nothing to memorise.

![Junk Store Pro Controller Hints overlay showing the SELECT button shortcuts for Settings, File Operations, File Browser and Diagnostics](/assets/images/blog/tips/button-chords/junk-store-chords.webp)

---

<h2 style="text-align: left !important; margin-left: 0;">SELECT + A: Settings</h2>

Check your Junk Store version and system details at a glance. It's also where the developer mode toggle lives, under System.

![Junk Store Pro Settings System page on Steam Deck showing the Junk Store version, build and extension channels, and Install Update and Install Dependencies buttons](/assets/images/blog/tips/button-chords/select-a.webp)

---

<h2 style="text-align: left !important; margin-left: 0;">SELECT + B: File Operations</h2>

Keep an eye on long-running file jobs like copying and deleting, with live progress so you can carry on gaming while they finish in the background.

![Junk Store Pro File Operations panel on Steam Deck showing an active Copying Files job at 1 percent, pulling a folder from another Junk Store device over the network at 28.81MB/s with a live ETA and a Cancel Operation button](/assets/images/blog/tips/button-chords/select-b.webp)

---

<h2 style="text-align: left !important; margin-left: 0;">SELECT + X: File Browser</h2>

Browse and manage your game folders straight from Game Mode, no Desktop Mode needed. It also includes the built-in Disk Analyser, so you can see exactly what is eating your storage and clear it out.

![Junk Store File Manager open in Steam Deck Game Mode, browsing Steam compatdata game folders with the quick-access sidebar](/assets/images/blog/tips/button-chords/select-x.webp)

To dig into storage, open a folder's context menu (right-click, or LT on the Deck) and choose **Disk Usage**.

![Junk Store File Manager context menu on a Compatdata folder showing Open in Active Pane, Disk Usage and Cancel, with Disk Usage highlighted](/assets/images/blog/tips/button-chords/disk-usage-menu.webp)

From there you get a colour-coded map of everything in that folder, sized by how much space it is using, so the storage hogs jump straight out and you can clear them without guesswork.

![Junk Store Disk Usage view on Steam Deck showing a colour-coded treemap of Epic game folders sized by disk space, totalling 2.9 GB, with each folder's size listed](/assets/images/blog/tips/button-chords/disk-usage-treemap.webp)

---

<h2 style="text-align: left !important; margin-left: 0;">SELECT + Y: Diagnostics</h2>

Access system tools and troubleshooting features, with the diagnostics framework flagging Junk Store issues automatically:

- **Processes** - Process Monitor to see what's running
- **Status** - System Status and Steam APIs
- **Backend Tests** - Run diagnostics
- **System Info** - View system information

![Junk Store Pro Diagnostics Process Monitor on Steam Deck listing running processes with CPU, memory and RSS columns, alongside Status, Backend Tests and System Info tabs](/assets/images/blog/tips/button-chords/select-y.webp)
